# Basic Java Conditions ☕

Welcome to my **Basic Java Conditions** repository!

This is my first GitHub repository, created as part of my journey to learn and practice Java programming. It contains beginner-friendly programs that demonstrate the use of conditional statements in Java.

## 📚 Concepts Covered

* `if` statement
* `if-else` statement
* `else-if` ladder
* Nested `if` statements
* Decision-making in Java

## 💻 Example Programs

The programs in this repository are designed to help beginners understand how Java makes decisions based on different conditions.

Examples may include:

* Checking whether a number is positive or negative
* Checking whether a number is even or odd
* Finding the greatest of two or three numbers
* Checking eligibility based on a condition

## 🛠️ Technologies Used

* **Language:** Java
* **IDE:** Any Java-compatible IDE or text editor

## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the `.java` files in your preferred IDE.
4. Compile and run the program.
